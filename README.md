# tottenham-rebuild-analytics

## トッテナム・ホットスパーの近年の成績低迷（弱体化）の真因をxG/xGAデータを用いて解明し、BIG6復権を目指すための補強・運用戦略を提案するデータ分析プロジェクトです。

## データの出典・謝辞 (Data Source & Credits)

本プロジェクトで使用しているデータおよびAPIは、以下の提供元の利用規約・ガイドラインに準拠して取得・利用しています。

- **データ提供元 (Data Provider):** [Understat](https://understat.com/)
  - プレミアリーグ等の各試合における xG（Expected Goals）および詳細なスタッツデータを提供しています。
- **データ取得ライブラリ (Data Extraction Tool):** [understatAPI](https://github.com/collinb9/understatAPI) (by Collin Bennett)
  - Understat からデータを効率的に取得するための Python API ラッパーライブラリです。

> **免責事項:** 本プロジェクトは非営利の個人的なデータ分析・ポートフォリオ作成を目的としており、記載されている分析結果および意見は個人の考察に基づくものです。
